# TriClean

TriClean is a smart three-in-one cleaning robot designed to sweep,
vacuum, and mop.

## Features
- Sweeping, vacuuming, and mopping
- Noise reduction
- Multilingual voice detection
- Facial expressions
- Solar panel
- Heat protection
- Smart cleaning schedule based on user habits

## Goal
TriClean aims to make household cleaning more efficient and convenient
through robotics, AI, and sustainable technology.
